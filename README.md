## 📂 Estructura del proyecto

```
portafolio/
│
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos generales del sitio
├── js/
│   └── main.js         # Lógica e interactividad
├── assets/
│   ├── img/             # Imágenes y capturas de proyectos
│   └── icons/           # Íconos (redes sociales, tecnologías, etc.)
└── README.md
```

## 🛠️ Tecnologías utilizadas

- **HTML5** — estructura semántica del sitio
- **CSS3** — estilos, responsive design y animaciones
- **JavaScript (Vanilla)** — interactividad (menú, filtros de proyectos, formulario de contacto, etc.)

## ✨ Características

- Diseño responsive (adaptado a móvil, tablet y escritorio)
- Sección "Sobre mí" con presentación profesional
- Galería/grid de proyectos con enlaces a demo y repositorio
- Sección de habilidades técnicas
- Formulario de contacto
- Animaciones al hacer scroll (Intersection Observer)

## 📦 Cómo usar este proyecto

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/portafolio.git
   ```
2. Entra a la carpeta del proyecto:
   ```bash
   cd portafolio
   ```
3. Abre `index.html` en tu navegador (o usa una extensión como Live Server en VS Code).

No requiere instalación de dependencias ni build: es HTML, CSS y JS puros.
